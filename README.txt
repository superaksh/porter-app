Build the APK (no Android Studio needed)
1. Create a new empty repository on github.com.
2. Upload everything in this folder to it (keep the .github folder).
3. Open the repository's Actions tab, pick "Build APK" and wait about 5 minutes.
4. Open the finished run, download "porter-commission-apk", unzip it and install app-debug.apk on your phone (allow installs from unknown sources).

The app screen is www/index.html. Edit it and push again to rebuild.
